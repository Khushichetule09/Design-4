# AI SaaS Landing Page

A modern SaaS landing page built using Next.js with a clean dark UI and a high-impact hero section.

## Features

* Split-screen hero section (text + image)
* Dark, minimal UI design
* Strong typography hierarchy
* Customizable hero image
* Responsive layout (mobile-friendly)
* Smooth transitions and hover effects

## Tech Stack

* Next.js
* React
* Tailwind CSS
* Google Fonts

## Preview

This project includes:

* Bold hero heading
* Subtle highlighted subtext
* Call-to-action button
* Full-height hero image section

## Responsive Design

* Desktop: split layout (text + image)
* Mobile: stacked layout
